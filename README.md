# ФимКино

Сайт школы юных гитаристов. Статика для GitHub Pages.

## Локальный просмотр

Откройте `index.html` в браузере или:

```bash
npx --yes serve .
```

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`
